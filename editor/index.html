SCHEMA 01

Il titolo italiano genera lo slug automaticamente.

02

Tag

Caricamento dei tag…

03

Ingredienti

Organizza gli ingredienti in gruppi e aggiungi voci che non fanno parte della dispensa. Gli ID esistenti compaiono mentre digiti.

Caricamento del catalogo…

Le voci vengono mostrate nella ricetta, ma non compaiono nella dispensa né vengono conteggiate tra gli ingredienti mancanti. Per un ingrediente senza quantità, inserisci l’indicazione (per esempio “q.b.” / “to taste”) nel campo unità: verrà mostrata da sola.

04

Procedimento

Separa i paragrafi con una riga vuota.

05

Note e conservazione

Facoltative; non compaiono nel sito se lasciate vuote.

Il file verrà salvato sul tuo dispositivo.

PROSSIMO PASSAGGIO

Aggiungi la ricetta al sito

✓

Aggiorna recipes-index.json

Apri il file nella cartella principale del progetto. Dentro l’array "recipes", incolla questa voce prima della parentesi quadra ] di chiusura:

  1. Se l’ultima voce esistente non ha la virgola, aggiungila dopo la sua parentesi graffa }.
  2. Incolla la nuova voce qui sotto, senza aggiungere una virgola dopo l’ultima voce dell’array.
  3. Salva recipes-index.json. Controlla che il JSON resti valido.

      

      
Metti il file scaricato in data/recipes/. Poi ricarica il sito per verificare la ricetta. Per pubblicarla, carica su GitHub sia il file JSON sia recipes-index.json.
